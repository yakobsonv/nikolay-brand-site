Этот файл читает Claude при каждом старте. Устройство и команды — [README.md](README.md).

**Репозиторий открытый.** В нём только код и данные, которые и так видны на сайте. Требования клиента,
источники текстов, очередь работ и открытые вопросы — во внутренних заметках: их ты читаешь через API доски

## Что это

Сайт-визитка компании, которая торгует стройматериалами в Москве и области (облицовочный кирпич, ЖБИ, арматура,
сухие и цветные кладочные смеси, тротуарная плитка, кровля, пластиковые окна, товары для благоустройства и ремонта)
и оказывает услуги (дизайн-проект, ремонт, строительство домов, укладка плитки).
Превью: **https://nikolay-brand-code.vercel.app** (проект Vercel `nikolay-brand-code`). Домена пока нет.

Главная: небольшой баннер → плитки материалов и услуг со ссылками на страницы → производители → для кого.
**Без цен и каталогов.** Ярко и жизнерадостно — не серо и не мрачно.

**Внутренние материалы** (читать через API доски, статья базы знаний «Обсидиан заказчика и общая ЛЕНТА»):
- папка `Сотрудник/материалы/Визитка Николая` — полная прежняя версия этого файла и очередь работ «Что осталось»;
- папка клиента `Николай (стройматериалы)` — передача проекта, требования, источники текстов и фото, журнал сборки.
Расходятся с этим файлом — главнее заметки.

## Правила (нарушение = работа не сделана)

1. **Не выдумывать факты о компании.** Марки, производители, сроки, доставка, гарантии, монтаж, «в наличии»,
   «наши объекты», «официальный дилер», годы и числа — только из материалов клиента (внутренние заметки) и слов Влада.
   Нужен новый факт — спросить Влада. Где фактов нет — общее описание категории товара и мягкие формулировки
   («подскажем», «рассчитаем», «покажем образцы кирпича и плитки в шоу-руме»).
2. **Служебного на странице быть не должно** («уточнить», «по данным клиента», «TBD»). Пометки — в отчёт на доске
   или в свою папку «Сотрудник» в Обсидиане, не в данные: всё, что лежит в `src/data/**`, может оказаться на экране.
   Проверять собранный HTML (`dist/`), а не исходник.
3. **Фото — каждый кадр смотреть глазами.** Без водяных знаков, чужих логотипов, надписей на английском, мрачных кадров.
   Unsplash — только `premium:false` и `plus:false`. Происхождение каждого файла — запись в `photos-manifest/*.json`.
   Стандарт размера: исходник ≥ показанного на 1440@1, растяжение ≤ 1,33 на 390@2.
4. **Цены не ставим** (визитка). Цены и наличие — ссылками на живые витрины компании.
5. **Живые сайты компании не трогать** — только читать.
6. **Пока нет домена — noindex в трёх местах** (метатег в `Base.astro`, `X-Robots-Tag` в `vercel.json`, `public/robots.txt`).
   Снятие noindex — отдельное решение Влада при запуске на домене.
7. **«Готово» = выложено и проверено своим рендером на выложенной версии** (`?v=<случайное>`), 1440, 768, 390 и 320,
   глазами каждую затронутую секцию **плюс клики** (меню, баннер, лайтбокс, FAQ). Скрипт `scripts/audit.py` — помощник,
   не единственная правда.
8. **Браузер для скриптов — только Playwright (Chrome for Testing)**, не обычный Chrome.
9. **Репозиторий открытый: секретов (токены, пароли, ключи) и внутренней кухни клиента** (созвоны, переписка, деньги,
   доступы, планы) сюда не класть — ни в код, ни в комментарии, ни в документы, ни в сообщения коммитов.
10. **Отчёт о работе — на доске задач** (`yakobsonv.com/ru/cabinet/staff`, проект `kirpichtrest`): что сделано, ссылка
    на выложенную версию, как проверено. Решений, которых нет в заметках, не додумывать — спрашивать Влада.

- **Репозиторий:** https://github.com/yakobsonv/nikolay-brand-site (аккаунт `Paul1l` — право записи; приглашение

- ⚠️ **Старый клон `nikolay-brand-code` не переносить сюда.** Не делать `git remote set-url` на этот репозиторий,
  не сливать и не перебазировать в него старую историю: в ней есть внутренние документы. Только свежий клон:
  `git clone https://github.com/yakobsonv/nikolay-brand-site.git`. Свои незапушенные правки из старого клона
  переносить файлами, не коммитами.
- Для пуша нужна авторизация GitHub (`gh auth login` или SSH-ключ). Перед работой — `git pull`.
- **Окружение:** Node ≥ 22.19. Зависимости — `npm ci` (не `npm install`: он переписывает `package-lock.json`).
  `npm audit fix --force` и обновление пакетов — только по слову Влада.
  Python 3.10+ для скриптов: `python3 -m venv .venv && . .venv/bin/activate && pip install playwright pillow && python -m playwright install chromium`

- **Выкладка = `git push origin main`.** Это превью на *.vercel.app с noindex, а не боевой сайт клиента. Перед пушем —
  сборка и проверка типов без ошибок. В `main` запрещены force-push и merge-коммиты — только линейная история.
- **После пуша** — статус Vercel у коммита на GitHub: зелёная галочка или
  `gh api repos/yakobsonv/nikolay-brand-site/commits/<sha>/status -q .state` → `success`. Затем рендер выложенной
  версии с `?v=<случайное>`. Красный статус или сайт сломан — `git revert <sha> && git push origin main` и сразу
  написать Владу.
- Из России *.vercel.app открывается через раз: повторить или проверить через VPN; не открылось совсем — проверить
  локально (`npm run build && npm run preview`) и прямо написать в отчёте, что выложенная версия не проверена.
- **Ширины проверки:** 1440, 768, 390 и 320.
- **Снимки экрана в репозиторий не класть.** В отчёте — адрес, ширина и что видно.

## Грабли, уже наступленные (не повторять)

- **`backdrop-filter` на шапке** делает её опорной рамкой для `position:fixed` — панель меню на телефоне схлопывалась
  до 64 px. Размытие — отдельным слоем `.hdr::before`.
- **Скоуп стилей Astro не доходит до элементов дочернего компонента**: классы, переданные в `<Icon class>` / `<Img class>`,
  стилизовать через `:global(...)`.
- **`aspect-ratio` + `min-height`** превращает минимальную высоту в минимальную ширину — блок распирал страницу на 390.
- **srcset в портретном боксе с `object-fit: cover`**: нужная ширина кадра = высота × пропорция; `sizes="100vw"` занижает.
  У `<img srcset>` `naturalWidth` поделён на плотность — растяжение считать по ширине файла (`-2000.webp` и т.п.).
- **Наследование цвета**: на телефоне карточка первого экрана светлая с тёмным текстом — плашки на красном задавать
  `color:#fff` явно (было 3,35:1).
- **Детектор контраста** снимать с `transition:none` и скрывать кнопку «наверх» / куки-баннер, иначе ложные срабатывания.
- **Типографика**: тексты из данных проходят `deepTypo()` (`src/lib/format.ts`) — неразрывные пробелы перед тире и после
  коротких слов, «15–20» и «дизайн-проект» не рвутся. Новые поля, которые не должны меняться (адреса, slug), — в `SKIP_KEYS`.
- **Временная папка `/private/tmp` чистится** — рабочие данные держать в репозитории или в своей папке Обсидиана.
